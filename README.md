# Marketing Analytics Portfolio Project

A data analytics project that analyzes marketing campaign performance using SQL, Python, and Power BI.

## Project Overview

This project investigates declining customer engagement and conversion rates for an e-commerce company. It combines SQL, Python, and Power BI to uncover insights from campaign data, customer journeys, and product reviews.

## Business Objectives

- Increase conversion rates
- Improve customer engagement
- Analyze customer sentiment
- Optimize marketing ROI

## Technologies Used

- SQL Server
- Python
- Pandas
- NLTK
- Power BI
- DAX

## Project Components

### SQL Analysis
- Customer journey analysis
- Engagement metrics
- Product and customer dimension tables

### Python Sentiment Analysis
- Processes customer reviews
- Calculates sentiment scores using VADER
- Categorizes reviews as Positive, Negative, Neutral, or Mixed

### Power BI Dashboard
Interactive dashboard showing:
- Conversion Rate
- Customer Engagement
- Average Order Value
- Customer Feedback Score
- Sentiment Trends

## Key Insights

- Conversion rates fluctuated significantly across months
- Blog content generated the highest views
- Positive customer sentiment dominated reviews
- Average customer rating remained around 3.7/5
